# 常用命令

按<kbd>/</kbd>打开控制台。命令和参数之间用空格分隔；方括号表示可选参数，不需要原样输入。执行`/help`或直接执行`/mp`、`/skin`可以查看游戏内帮助。

## 联机

| 命令                           | 说明                                                   |
| ------------------------------ | ------------------------------------------------------ |
| `/mp start [port]`             | 创建房间；不填写端口时默认使用`40815`                  |
| `/mp stop`                     | 停止联机服务并关闭当前房间                             |
| `/mp restart`                  | 使用当前端口重新创建房间                               |
| `/mp connect <address> [port]` | 加入房间；支持`IP:端口`或把端口写成第二个参数          |
| `/mp disconnect`               | 断开连接；房主执行时会让所有加入者离开                 |
| `/mp status`                   | 查看连接状态、人数、所在场景和在线玩家                 |
| `/mp id <id>`                  | 设置玩家ID，并把变更同步给房间内其他玩家               |
| `/mp maxplayers [count]`       | 查看或设置最大玩家数；人数包含房主，最小为2，默认值为2 |
| `/mp kick id <name>`           | 房主按玩家ID踢人                                       |
| `/mp kick uid <uid>`           | 房主按玩家列表中的编号踢人                             |
| `/mp continue day`             | 房主在已结束白天流程时，强制跳过离开的玩家继续         |
| `/mp continue prep`            | 房主确认开店前设置后，强制跳过离开的玩家继续           |
| `/mp ipv6 enable`              | 房主允许通过IPv6地址加入，IPv4仍可使用                 |
| `/mp ipv6 disable`             | 关闭IPv6连接                                           |

## 皮肤

| 命令                                                           | 说明                                           |
| -------------------------------------------------------------- | ---------------------------------------------- |
| `/skin list`                                                   | 列出当前游戏和ResourceEx提供的可用角色皮肤     |
| `/skin set <characterId> <Default\|Explicit\|DLC> <skinIndex>` | 切换角色和服装                                 |
| `/skin off`                                                    | 恢复游戏默认角色外观                           |
| `/skin net <name>`                                             | 从皮肤站加载指定名称的网络皮肤                 |
| `/skin net refresh`                                            | 清除缓存并重新下载当前网络皮肤                 |
| `/skin net off`                                                | 关闭网络皮肤并恢复默认外观                     |
| `/skin rot on`                                                 | 强制允许角色贴图旋转                           |
| `/skin rot off`                                                | 强制禁止角色贴图旋转                           |
| `/skin rot clear`                                              | 清除旋转覆盖，立即恢复皮肤或游戏的默认旋转设置 |

## 资源包

| 命令                      | 说明                                                   |
| ------------------------- | ------------------------------------------------------ |
| `/resourceex list`        | 列出成功加载和被拒绝的资源包                           |
| `/resourceex info <name>` | 按ZIP文件名、`label`或显示名称查看资源包信息和内容统计 |

## 聊天和直播

不以`/`开头的输入会作为聊天消息发送。

直播隐私模式命令如下：

| 命令            | 说明                                   |
| --------------- | -------------------------------------- |
| `/live`         | 启用直播隐私模式                       |
| `/live partial` | 隐藏玩家ID并标出需要外部遮挡的聊天区域 |
| `/live full`    | 隐藏玩家ID和聊天内容                   |
| `/live off`     | 关闭直播隐私模式                       |

## 其他

| 命令                         | 说明                                     |
| ---------------------------- | ---------------------------------------- |
| `/help`                      | 列出已注册命令                           |
| `/clear`                     | 清空控制台显示内容                       |
| `/whereami`                  | 在白天场景显示当前地图和坐标             |
| `/get currentactivemaplabel` | 显示当前地图名称                         |
| `/get pos`                   | 显示当前位置                             |
| `/link MetaMystia`           | 打开MetaMystia仓库                       |
| `/link Izakaya`              | 打开东方夜雀食堂小助手                   |
| `/call try_close_izakaya`    | 营业结束流程卡住时，尝试强制结束本地营业 |

`/debug`、`/webdebug`和其他`/call`子命令用于开发和诊断，可能直接改变游戏状态，不建议普通玩家使用。
